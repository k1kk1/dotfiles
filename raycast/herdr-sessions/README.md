# Alfred migration: Herdr Sessions

This local Raycast extension replaces the two Alfred workflows that used the
`hs` and `hr` keywords, plus the `cheet` shortcut for the local HTML cheat
sheet.

Run `npm install && npm run dev` in this directory once to import the extension
into Raycast. The Raycast command keywords preserve the former Alfred entry
points: `cheet`, `hs`, and `hr`.
